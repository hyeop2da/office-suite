# 실행 방법

필요: Node.js 24 이상, 시험의 일부는 파이썬 3 + `python-docx`(선택).

```bash
cd office-suite
npm install
```

## 시험

```bash
npm test
```

## 분석 도구

```bash
node tools/compare.ts fixtures/hwpx/pipc-privacy-20231127.hwpx fixtures/hwpx-rhwp-saved/pipc-privacy-20231127.hwpx
```

```bash
node tools/inventory.ts --md
```

```bash
python -I -X utf8 tools/hwp_inspect.py fixtures/hwp --md
```

## 브라우저 자동 시험

```bash
npx playwright install chromium webkit
```

```bash
npm run test:e2e
```

4173 포트에 서버가 떠 있으면 재사용하므로, 코드를 고친 뒤에는 그 서버를 먼저 끈다.

## 웹앱 빌드와 실행

```bash
npm run build
```

```bash
npm run serve
```

브라우저에서 `http://127.0.0.1:4173/`을 연다. 한 번에 하려면 `npm run dev`.

같은 Wi-Fi의 스마트폰에서 시험하려면 `tools/serve.mjs`가 기본으로 127.0.0.1에만 열리므로 `listen` 주소를 PC 주소로 바꿔야 한다(HTTPS가 아니면 일부 브라우저 기능이 제한될 수 있다). 이 경로는 아직 시험하지 않았다.

## 사용

1. "파일 열기" 또는 "샘플"에서 HWPX·DOCX 문서를 연다.
2. 문단 칸을 눌러 글자를 고친다. 바뀐 문단은 노랗게 표시되고 "되돌리기"가 나타난다.
3. "저장·다운로드"를 누르면 `원본이름-수정.확장자`가 내려받아진다. 저장본을 다시 열어 확인한 뒤에만 내려받는다.
4. 편집 중 내용은 이 브라우저(IndexedDB)에 임시 보존된다. "임시 보존" 스위치로 끄고, "임시 저장 지우기"로 삭제한다. 다음에 열면 "이어서 하기"가 나온다.

## 배포

배포하지 않았다. `dist/` 폴더가 정적 파일 전체이므로 어떤 정적 호스팅에 올려도 된다. 올리기 전에 한컴 표기 문구(앱 정보 화면)를 추가해야 한다.

## 폴더

`src/` 코어와 앱, `web/` 화면, `test/` 시험, `fixtures/` 시료, `tools/` 빌드·서버·시료 생성, `docs/` 문서, `../backup-2026-10-22/` 이번 수정 전 백업.
