# 기능 대응표 (구현 상태)

상세 1,115행은 `../기능대응표_초안.xlsx`(한컴오피스 2022 도움말 기준)에 있다. 이 문서는 **우리 앱의 실제 상태**만 올린다. 한글 2002와의 기능 차이는 조사하지 않았다(미확인).

## 용어 (엄격하게 구분)

| 표시 | 뜻 |
|---|---|
| **구현 완료** | 코드가 있고 자동 시험을 통과함(독립 도구 대조 포함). **원본 프로그램에서는 확인하지 않음** |
| **부분 구현** | 일부 경우만 동작 |
| **검증 완료** | **원본 프로그램(한/글·Word 등)에서 열어 확인함** |
| **미검증** | 시험하지 않음 |
| **미구현** | 코드 없음 |

**"검증 완료"는 한/글 2022(12.0.0.4426)에서 화면으로 확인한 아래 항목뿐이다.** Word 등 나머지는 원본 프로그램에서 연 적이 없다.

| HWPX 항목 | 한/글 2022 확인 범위 |
|---|---|
| 편집본 열기·쪽 수·글자 수·표시 | 검증 완료(시료 4~5개, 짧은 삽입) |
| 줄 수가 늘어나는 본문 편집(drop) | 검증 완료(시료 1개) |
| 줄 수가 늘어나는 표 셀 편집(drop) | 검증 완료(시료 1개) |
| 줄 배치 캐시 keep | **부적합으로 확인**(글자 겹침) |
| 편집본을 한/글에서 다시 저장한 뒤 구조, 인쇄·PDF 출력, 그림·글상자 편집 후 표시 | 미검증 |

## 기능별 (HWPX / DOCX)

| 기능 | HWPX | DOCX | 근거 |
|---|---|---|---|
| 무수정 저장 바이트 보존 | 구현 완료 | 구현 완료 | 단위 시험 |
| 본문 문단 글자 편집 | 구현 완료 | 구현 완료 | 단위·브라우저 시험 |
| 표 셀 글자 편집 | 구현 완료(실제 한/글 시료) | 구현 완료(생성 시료) | 단위 시험 |
| 글자 모양별 조각(런) 보존 | 구현 완료 | 구현 완료 | 단위 시험 |
| 머리말·꼬리말 | 부분 구현(합성 XML로 분류만) | 구현 완료(생성 시료) | HWPX는 한/글 시료에 해당 요소 없음 |
| 각주·미주 | 미검증(분류만) | 미검증 | 시료 없음 |
| 글상자 | 부분 구현(분류만) | 검증 완료(Word가 선택 쪽 글자를 읽음). 한계: Fallback 쪽 글자는 옛 값으로 남음 | Word 2024 |
| 여러 구역 | 미검증 | 해당 없음 | 시료 없음 |
| 줄 배치 캐시 정책 | 검증 완료(기본 drop, keep은 부적합) | 해당 없음 | 한/글 2022 E3·E4 |
| 미리보기·수정 일시 갱신 | 부분 구현(호출 시에만, 단위 시험) | 미구현 | 한/글 반응 미확인 |
| 문단 나누기, 줄바꿈·탭 삽입 | 구현 완료(본문 단순 문단, rhwp·바이트 보존 확인) | 구현 완료(탭·줄바꿈 삽입, 문단 나누기, python-docx 확인). **삽입한 탭·줄바꿈이 `paragraphs().text`에도 반영됨(2026-10-22)** | **검증 완료**: 한/글 2022(HWPX, 화면 캡처)·Word 2024(DOCX, COM)·PowerPoint 2024(PPTX, COM) 모두 실제로 열어 확인함(2026-10-22~23). `탭-줄바꿈-문단나누기.md` |
| 글자·문단 모양 편집 | 미구현 | 미구현 | |
| 그림·도형·수식·하이퍼링크 편집 | 미구현 | 미구현 | 하이퍼링크는 한/글 시료에 없음 |
| 쪽 레이아웃 표시 | 부분 구현(rhwp 읽기 전용 쪽 미리보기, 편집본 반영. 한/글 시각 비교 미실시) | 미구현 | HWPX 5개는 한/글과 쪽 수 일치 |
| 인쇄·PDF 내보내기 | 미구현 | 미구현 | |
