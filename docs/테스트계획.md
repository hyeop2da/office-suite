## 자동 브라우저 시험 (Playwright, 2026-10-22 추가)

```bash
npm run test:e2e
```

`playwright.config.ts`가 `npm run dev`(빌드 후 정적 서버)를 띄운다. 이미 4173 포트에 서버가 떠 있으면 재사용하므로 **코드를 고쳤다면 먼저 그 서버를 끄고** 실행한다(오래된 빌드로 시험하는 것을 막기 위해).

| 프로젝트 | 엔진 | 에뮬레이션 |
|---|---|---|
| android-chrome-pixel7 | Chromium | Pixel 7 |
| ios-safari-iphone15 | WebKit | iPhone 15 세로 |
| ios-safari-iphone15-landscape | WebKit | iPhone 15 가로 |
| ipados-safari-ipad-pro-11 | WebKit | iPad Pro 11 |

시나리오 34개 × 4 프로젝트 = 136개(오프라인 3개 포함, `e2e/offline.spec.ts`): 첫 화면(가로 스크롤 없음, 안내문, 콘솔 오류·외부 요청 없음), 터치 대상 40px 이상, HWPX 열기→편집→저장→**다운로드 파일을 Node 코어로 독립 검증**(바뀐 ZIP 항목은 본문 하나), 무수정 저장본 바이트 동일, 표 셀 편집, **탭·줄바꿈을 그대로 넣고 저장·재열기해도 유지(2026-10-23, 이전의 "공백으로 바뀜" 시험을 대체), 탭·줄바꿈 단추로 커서 위치에 끼워 넣기(2026-10-23 신규)**, 되돌리기, 도구 모음 위치·여백, DOCX 표 편집, 임시 보존 복구·삭제·끄기, PDF·구형 HWP·손상·빈 파일 안내, 파일 선택기 경로와 저장 파일명.

**한계**: 에뮬레이션은 화면 크기·터치·UA를 흉내 낸다. Playwright WebKit은 Windows용 WebKit 빌드이며 **실제 iOS Safari가 아니다**(iOS의 파일 선택기·다운로드 UI·가상 키보드·IME 조합·메모리 한도는 시험하지 못함). 다운로드는 Playwright가 가로챈 파일을 검증한 것이다.
